# CV conventions by country

`src/lib/cv/conventions.ts` holds what each country's CV contains and how it prints. Researched October 2026; sources below.
Items not confirmed by a source use common practice (A4 outside North America; 15–25 mm margins).

| Country | Paper | Personal details on the CV | References | End of CV |
|---|---|---|---|---|
| Bangladesh | A4 | Father's and mother's name, DOB, nationality, marital status, religion, permanent address; photo | Two non-related referees with full details | Declaration, date, signature |
| India (private sector) | A4 | Nationality, work status, notice period; no father's name or religion | Available on request | None |
| Pakistan | A4 | DOB, nationality, marital status, notice period | Two non-related referees | None |
| Sri Lanka | A4 | DOB, nationality, marital status; no parents or spouse | Two referees | Declaration, signature |
| Nepal | A4 | Nationality; no religion, marital status or citizenship number | On request | None |
| UAE / Saudi Arabia / Qatar / Gulf | A4 | Nationality, DOB, marital status, visa status, driving licence, notice period; photo | On request | None |
| Malaysia | A4 | Nationality, work pass, notice period; no IC, race or religion | Three referees with title, phone, email, relationship | None |
| Singapore | A4 | Nationality, work pass, notice period; never NRIC, race, religion or marital status | On request | None |
| Philippines | Letter | Nationality, work status | Three character references | None |
| United Kingdom | A4 | Right to work only; no photo, DOB, nationality or marital status | On request | None |
| Ireland | A4 | Right to work | Two referees | None |
| United States / Canada | Letter | Work authorization only | Separate sheet, not on the résumé | None |
| Australia | A4 | Work rights, driving licence | Two referees with full details | None |
| New Zealand | A4 | Work rights, driving licence | On request | None |
| Germany / Austria | A4, 25 mm left margin | DOB, nationality, work permit, driving licence | Not listed (work certificates are attached) | Place, date and signature |
| Switzerland | A4 | DOB, nationality, permit L/B/C | On request | None |
| Netherlands | A4 | DOB, nationality, work permit | Not listed | None |
| France | A4 | Work permit, driving licence | Not listed | None |
| Spain | A4 | DOB, nationality, driving licence | On request | None |
| Italy | A4 | DOB, nationality, work permit, driving licence | Not listed | GDPR consent line, date, signature |
| South Africa / Kenya | A4 | Nationality, driving licence, work permit; no photo | Three referees | None |
| Nigeria | A4 | Nationality, work permit | On request | None |

Every item is shown only when the person typed it; nothing is generated.
